# Конфигурация

Что читает каждый запуск, как проверяется файл, настройки `[general]` и
`[strings]`. Ключи каждого назначения описаны на странице
[Цели](targets.ru.md) и в разделе [Ключи целей](#ключи-целей), очередь -
на странице [Спул и очередь](spool.ru.md), журнал - на странице
[Журнал](logging.ru.md).

Программа читает `/etc/mailcrier.conf`, файл TOML. Каждый запуск разбирает
файл строго: неизвестный ключ, ключ, который тип цели не использует, или
недопустимое значение отклоняют файл, письмо не доставляется, а
задерживается в спуле (см. [Спул и очередь](spool.ru.md)), и код
выхода - 78. Пакет устанавливает пример без целей, поэтому, пока цели не
настроены, каждое письмо задерживается с кодом 78; так и должно быть.

## Термины

| Термин | Значение |
|---|---|
| цель | одна таблица `[target.<name>]`: назначение писем, см. [Цели](targets.ru.md) |
| маршрут | правило `[[route]]`, которое выбирает цели письма, см. [Маршруты и подавление](routing.ru.md) |
| правило подавления | правило `[[suppress]]`, которое отбрасывает письмо: оно не отправляется и не попадает в спул |
| личный чат | получатель `<chat>@telegram`, который называет чат Telegram, см. [Личные чаты](routing.ru.md#личные-чаты) |
| спул | каталог `/var/spool/mailcrier`, где письмо ждёт, пока его не получит каждая цель, см. [Спул и очередь](spool.ru.md) |
| запись спула | одно письмо в спуле: `<id>.eml` - само письмо, и `<id>.json` - его состояние по каждой цели, он же файл состояния |
| каталог | подкаталог спула: `tmp/` во время записи, `queue/` - ожидание повтора, `hold/` - ожидание конфигурации, которая загрузится, или маршрута, `failed/` - попытки прекращены, `locks/` |
| прогон очереди | проход по спулу, который повторяет доставку в цели, чей срок подошёл: после каждого вызова - для писем его пользователя, и `mailcrier -q` из таймера или cron каждые 5 минут |
| временная ошибка | ошибка, которую очередь повторяет: таймаут, потерянное соединение, статус 429 или 5xx, ответ с `Retry-After`, код выхода 75 у хука |
| постоянная ошибка | любая другая ошибка, без повторов: неверный токен или чат, отклонённый запрос, перенаправление |
| с повышенными правами через setgid | вызов пользователя, отличного от root, который получил группу `mailcrier` от бита setgid исполняемого файла, см. [Привилегии](privileges.ru.md) |

## Примеры

Примеры конфигураций, которые копируются целиком, устанавливаются в
`/usr/share/doc/mailcrier/examples/` и хранятся в
[`packaging/examples/`](../packaging/examples/):

| Файл | Что показывает |
|---|---|
| `mailcrier.conf` | каждую таблицу со значениями по умолчанию и по одной минимальной цели каждого типа, в виде комментариев, как установленный файл |
| `telegram.conf` | один чат Telegram с темой форума, `on_long` и `max_lines` |
| `team-chat.conf` | Slack, Discord и Mattermost вместе |
| `ntfy.conf` | ntfy с лимитом файлов ntfy.sh и шаблоном |
| `webhook.conf` | цели `http` с `method`, заголовками, шаблонами пути и запроса и `generic-json` |
| `hook.conf` | хук `exec` с `argv` и `timeout`, письмо на stdin |
| `routes.conf` | несколько целей, маршруты по получателю и теме, `continue`, правило без условий, `[[suppress]]` для шумного задания cron, `telegram_direct` |
| `templates.conf` | `template` и `template_file` с функциями шаблонов |
| `container.conf` | контейнер без бита setgid: спул на томе, секреты в `/run/secrets` |

## Общие настройки и уведомления

```toml
[general]
syslog_tag = "mailcrier"        # необязательный, по умолчанию "mailcrier"
http_timeout = "15s"            # необязательный, один HTTP-запрос
deadline = "30s"                # необязательный, доставка во все цели

[strings]                       # необязательный, уведомления вместо пропусков
no_subject = "(no subject)"
empty_body = "(empty body)"
truncated = "[truncated]"
truncated_size = "[truncated, %s in full]"
more_attachments = "... and %d more"
not_sent = "[not sent]"

[target.api]                    # ключ таблицы - имя цели: [a-z0-9-]
type = "http"
url_file = "/etc/mailcrier.d/api.url"   # или url = "https://..."
preset = "generic-json"
```

- Задаётся ровно один из ключей `url` и `url_file`, так же `token` и
  `token_file`. Ключ `*_file` принимает абсолютный путь; значением служит
  содержимое файла без пробельных символов по краям.
- `[strings]` заменяет английские уведомления, которые стоят на месте
  отсутствующего содержимого: `no_subject` - для письма без темы,
  `empty_body` - для тела без видимого текста, `truncated` - в конце тела,
  обрезанного до лимита длины цели, `truncated_size` - на его месте, когда
  полный текст не отправляется файлом, с `%s` для его размера (ровно один
  `%s` и никаких других `%`, иначе код выхода 78; если задан только
  `truncated`, он стоит и там, без размера), `more_attachments` - после
  списка вложений, обрезанного до этого лимита, с `%d` для числа
  пропущенных (ровно один `%d` и никаких других `%`, иначе код выхода 78),
  `not_sent` - после вложения, которое указано в тексте, но не отправлено,
  потому что превышает лимит файла цели. Каждый ключ необязателен и не
  может быть пустым; значения выше - значения по умолчанию. Пресет
  `generic-json` не использует ни одного из них: он передаёт тему и тело
  как есть, пустыми, если их в письме нет, и не имеет лимита длины.

## Таймауты и прокси

- `http_timeout` ограничивает один HTTP-запрос от установки соединения до
  конца ответа; `deadline` ограничивает доставку во все цели вместе. Оба
  принимают строки длительности Go (`"500ms"`, `"15s"`, `"1m"`) и должны
  быть положительными. Если цель исчерпала любой из них, это временная
  ошибка, и её текст называет ограничение, например
  `Post: http_timeout 15s exceeded` или `Post: deadline 30s exceeded`;
  `run_budget`, `drain_budget` и `timeout` хука выглядят так же, а сигнал
  остановки - как `terminated signal received`. Таймаут или закрытое
  соединение во время чтения ответа Telegram или Slack - тоже временная
  ошибка (`answer not read`), каким бы ни был статус.
- Переменные окружения прокси (`HTTPS_PROXY`, `HTTP_PROXY`, `NO_PROXY`)
  учитываются без повышенных прав и игнорируются процессом с повышенными
  правами через setgid.
- Маска прав создаваемых файлов всегда `007`.

## Ключи целей

Все ключи, которые принимает таблица `[target.<name>]`. Ключ, который тип
не принимает, отклоняет файл с кодом выхода 78, как и отсутствующий
обязательный ключ; токен или URL задаётся ровно одним из двух: ключом или
его формой `_file`.

| Ключ | Типы | Обязателен для | Значение | По умолчанию |
|---|---|---|---|---|
| `type` | все | все | `telegram`, `discord`, `slack`, `ntfy`, `http`, `exec` или `shoutrrr` | |
| `token` | `telegram`, `slack` | | токен бота; или `token_file` | |
| `token_file` | `telegram`, `slack` | | абсолютный путь к файлу с токеном | |
| `url` | `discord`, `ntfy`, `http`, `shoutrrr` | | абсолютный URL `http` или `https`, для `shoutrrr` - URL сервиса; или `url_file` | |
| `url_file` | `discord`, `ntfy`, `http`, `shoutrrr` | | абсолютный путь к файлу с URL | |
| `chat_id` | `telegram` | `telegram` | целое число или непустая строка, например `"@channel"` | |
| `message_thread_id` | `telegram` | | целое число, тема форума | |
| `disable_notification` | `telegram` | | `true` или `false` | `false` |
| `channel` | `slack`, `http` | `slack` | непустая строка; для `http` только с `preset = "mattermost"` | |
| `preset` | `http` | | `mattermost`, `slack-webhook` или `generic-json`; или шаблон | |
| `method` | `http` | | `POST`, `GET`, `PUT` или `PATCH` | `POST` |
| `username` | `http` | | строка, только с `preset = "mattermost"` | |
| `headers` | `http` | | таблица имён заголовков и шаблонов значений | |
| `path` | `http` | | шаблон, который дописывается к пути URL | |
| `query` | `http` | | таблица имён параметров запроса и шаблонов значений | |
| `argv` | `exec` | `exec` | список строк, первая - абсолютный путь | |
| `timeout` | `exec` | | положительная длительность Go | `"30s"` |
| `on_long` | `telegram`, `discord`, `slack`, `ntfy` | | `file`, `truncate` или `blockquote` | `file` |
| `long_file` | `telegram`, `discord`, `slack`, `ntfy` | | `text` или `eml` | `text` |
| `max_text` | `telegram`, `discord`, `slack`, `ntfy`, `http` | | положительное целое число, в единицах сервиса | лимит сервиса |
| `max_lines` | `telegram`, `discord`, `slack`, `ntfy`, `http` | | положительное целое число, строки тела | нет |
| `max_file_size` | `telegram`, `discord`, `slack`, `ntfy` | | положительное целое число, байты | лимит сервиса |
| `template` | `telegram`, `discord`, `slack`, `ntfy`, `http`, `shoutrrr` | | Go `text/template` | встроенный |
| `template_file` | `telegram`, `discord`, `slack`, `ntfy`, `http`, `shoutrrr` | | абсолютный путь к файлу с шаблоном | |
