# Цели

Цель - одна таблица `[target.<name>]`
[файла конфигурации](configuration.ru.md): одно место, куда уходят
письма. На этой странице - то, что общее у всех типов; у каждого типа
своя страница:

| Тип | Куда отправляет |
|---|---|
| [`telegram`](targets/telegram.ru.md) | в чат, группу или канал через бота Telegram |
| [`discord`](targets/discord.ru.md) | в канал Discord через его вебхук |
| [`slack`](targets/slack.ru.md) | в канал Slack с токеном бота |
| [`ntfy`](targets/ntfy.ru.md) | в топик сервера ntfy |
| [`http`](targets/http.ru.md) | в Mattermost, во входящий вебхук Slack, в JSON API или пингом GET |
| [`exec`](targets/exec.ru.md) | в свою программу, письмо на stdin |
| [`shoutrrr`](targets/shoutrrr.ru.md) | в сервис библиотеки shoutrrr: Gotify, Matrix, Teams, Pushover, SMTP и другие |

Каждая цель файла получает каждое письмо, если цели не выбирают маршруты
или личные чаты, см. [Маршруты и подавление](routing.ru.md); всем целям
письма оно отправляется одновременно. Каждая цель отправляет текст в
разметке своего сервиса, экранированный так, что ничто из письма не
становится разметкой, предпросмотром ссылки или упоминанием; `shoutrrr`
отправляет простой текст, а `exec` вместо текста передаёт само письмо.

`max_file_size`, ключ всех типов, кроме `http`, `exec` и `shoutrrr`,
задаёт лимит размера одного файла в байтах вместо указанного на странице
типа (у `slack` его нет); значение - положительное целое, иначе код
выхода 78. Файл больше лимита перечисляется в уведомлении `not_sent` и не
отправляется, а обрезанный текст, полный текст которого превышает лимит,
заканчивается уведомлением `truncated_size`. Значение выше лимита сервиса
берётся как есть, и файл больше лимита отклоняет сам сервис.

## Ограничения

Лимиты каждого сервиса, как их указывает страница его типа; `max_text` и
`max_file_size` заменяют их для отдельной цели, см.
[Длинные письма](long-messages.ru.md).

| Тип | Текст | Файлы |
|---|---|---|
| `telegram` | 4096 символов | 10, не больше 50 MB каждый |
| `discord` | 2000 символов | 10, не больше 20 MiB каждый и 25 MiB вместе |
| `slack` | 40000 единиц UTF-16 | 10, без лимита размера |
| `ntfy` | 4095 байт | 10, не больше 15 MiB каждый (ntfy.sh: 2 MB) |
| `http` | `slack-webhook` 40000 единиц UTF-16, `mattermost` 16383 символа, у `generic-json` нет | нет |
| `exec` | само письмо на stdin | нет |
| `shoutrrr` | у mailcrier нет, обрезает сервис | нет |

## Ошибки доставки

Каждая цель отказывает сама по себе; остальные всё равно доставляют.
Статус 429, 5xx и любой ответ с заголовком `Retry-After` - временные
ошибки, их повторяет спул; любая другая ошибка постоянная и не
повторяется. Таймаут `http_timeout` или `deadline` - тоже временная
ошибка, см. [Таймауты и прокси](configuration.ru.md#таймауты-и-прокси);
правила типа, отличные от этих, - на его странице.
