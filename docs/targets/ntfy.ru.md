# ntfy

Тип `ntfy` публикует в топик сервера ntfy. Ключи, которые принимает любая
цель, и как классифицируется ошибка: [Цели](../targets.ru.md); текст
длиннее лимита: [Длинные письма](../long-messages.ru.md).

```toml
[target.phone]
type = "ntfy"
# https://ntfy.sh/<topic>, допускается user:password@
url_file = "/etc/mailcrier.d/ntfy.url"
max_file_size = 2000000         # необязательно, ntfy.sh принимает файлы до 2 MB
```

Цель этого типа публикует JSON в корень сервера: топик, тему письма как
заголовок (переводы строк заменены пробелами, не больше 1 KB) и текст не
больше 4096 байт, затем по одному PUT на вложение в топик с `filename` и
`title` в параметрах запроса; до 10 файлов не больше 15 MiB каждый -
значения по умолчанию сервера ntfy. ntfy.sh принимает файлы не больше
2 MB, поэтому цель там задаёт `max_file_size`. URL должен заканчиваться
топиком, иначе код выхода 78; данные пользователя и параметры запроса,
например `auth`, отправляются с каждым запросом.
