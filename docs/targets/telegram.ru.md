# Telegram

Тип `telegram` отправляет через бота Telegram Bot API. Ключи, которые
принимает любая цель, и как классифицируется ошибка:
[Цели](../targets.ru.md); текст длиннее лимита:
[Длинные письма](../long-messages.ru.md).

```toml
[target.ops-telegram]
type = "telegram"
token_file = "/etc/mailcrier.d/telegram.token"  # или token = "123456:ABC..."
chat_id = -1001234567890                        # или "-1001234567890", "@channel"
message_thread_id = 42                          # необязательно, тема форума
disable_notification = true                     # необязательно, без звука
```

`chat_id` (целое число или непустая строка) обязателен. Письмо уходит через
`sendMessage` с `parse_mode` HTML и выключенным предпросмотром ссылок, затем
по одному `sendDocument` на вложение; текст не длиннее 1024 символов вместо
этого становится подписью первого документа, если этот файл не пустой.
Текст - не больше 4096 символов, как их считает Telegram, после разбора
сущностей; символ вне BMP, например эмодзи, считается один раз. Отправляется
до 10 файлов не больше 50 MB каждый, остальные перечисляются в уведомлении
`not_sent`. Ответ с `"ok": false` - ошибка даже со статусом 200;
`error_code` 429 и 5xx - временные ошибки, `parameters.retry_after` пишется
в журнал как `retry_after`. Если текст дошёл, а документ нет, письмо
считается доставленным, и в журнал пишется `attachments not delivered`.

## Бот и id чата

Цели нужен токен бота и id чата, в который бот может писать. Шаги
следуют документации Telegram Bot API
(<https://core.telegram.org/bots/api#getupdates>); `curl` запускается на
любом хосте с доступом к `api.telegram.org`.

1. В Telegram отправьте `/newbot` боту `@BotFather` и ответьте на его
   вопросы. Он присылает токен, например `123456:ABC-...`, который
   кладётся в `/etc/mailcrier.d/telegram.token`, как в разделе
   [Быстрый старт](../../README.ru.md#быстрый-старт).
2. Пустите бота в чат:
   - личный чат: откройте бота и отправьте ему `/start`; бот не может
     написать первым (`bot can't initiate conversation with a user`);
   - группа: добавьте бота участником, затем отправьте в группе
     `/start@<bot name>` - такая команда доходит до бота даже с включённым
     режимом приватности;
   - канал: добавьте бота администратором с правом публикации, затем
     опубликуйте сообщение в канале. Публичный канал принимает и своё
     имя пользователя, `chat_id = "@channel"`, без этого шага.
3. Прочитайте обновления, которые получил бот; токен не попадает в
   историю оболочки:

   ```sh
   curl -s "https://api.telegram.org/bot$(cat /etc/mailcrier.d/telegram.token)/getUpdates"
   ```

   id - это `"chat":{"id":...}` сообщения из шага 2: положительное число
   у личного чата, отрицательное у группы, `-100...` у супергруппы или
   канала. Пустой `"result":[]` означает, что обновлений ещё не было или
   что для бота задан вебхук: при нём `getUpdates` не работает.
4. Запишите это число в `chat_id` и проверьте командой
   `mailcrier --probe -- <target name>`: `class=perm status=400` называет
   причину, которую дал Telegram, например `chat not found`.

Группа, ставшая супергруппой, получает новый id, `-100...`; сообщения на
старый id отклоняются со статусом 400, пока не изменён `chat_id`.
